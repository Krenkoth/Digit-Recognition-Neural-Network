# Digit Recognition Neural Network

Basic neural network to recognize handwritten digits. Accuracy around 95%.

### Implementation

__Dataset:__ MNIST

There are implementations in this repository. 
- *Main.py* and *NeuralNet.py* implement the neural network with python and numpy
- *TF_Main.py* implements the same neural network using TensorFlow. This was created for an example for Coding Club


__Trained Network:__ *trainedNet.pkl* is a trained version of the manually implemented network that can be imported with pickle
